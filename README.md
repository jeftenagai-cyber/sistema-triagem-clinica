Sistema de Triagem Clínica
Este é um sistema inteligente de triagem de pacientes baseado no Protocolo de Manchester, desenvolvido para otimizar o fluxo de atendimento em unidades de saúde.

🚀 Funcionalidades
Triagem Automática: Classificação de risco via motor de inferência (Árvore de Decisão).

Fila Dinâmica: Gerenciamento de pacientes com ordenação por prioridade e tempo de chegada.

Histórico de Atendimentos: Registro de pacientes já atendidos com opção de reatendimento.

Interface Intuitiva: Painel de controle claro para visualização de chamadas.

🛠️ Tecnologias
Python

Jupyter Notebook (Google Colab)

HTML/CSS/JavaScript

📋 Como usar
Baixe o arquivo .ipynb deste repositório.

Importe o arquivo no seu Google Colab.

Execute todas as células para carregar a interface de triagem.
